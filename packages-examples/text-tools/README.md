# text-tools

An example Jarvis tool package, in Python: word, sentence and paragraph
counts with reading time, and case changes (UPPER, lower, Title, Sentence,
camelCase, snake_case). Uses only the standard library.

"Jarvis, how many words is this?" · "snake_case these names"

Needs `python` on the PATH. See the guide, `docs/PACKAGES.md`.
